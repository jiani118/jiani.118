# WebOS 网页桌面

一个纯前端（单个 `index.html`）的 Windows 风格网页桌面，无需构建、无需后端。

## 功能
- 液态玻璃窗口、开始菜单、任务栏、通知中心、锁屏（密码 / PIN / 系统指纹人脸 / 密保问题）
- 文件资源管理器、回收站、记事本、Word 文档、表格、PPT（可导入本地 docx / xlsx / pptx）
- 音乐（可从视频提取音频）、视频、相机、录音机
- 浏览器（书签 / 密码 / 历史 / 搜索引擎）、日历（可导入 .ics 节假日）、时钟（闹钟 / 倒计时 / 秒表 / 世界时钟）
- 计算器（历史记录 + 单位换算 / 房贷 / 汇率 / 进制）、8 个小游戏
- 天气：接入和风天气，当前位置优先，城市管理 + 详细预报
- 设置：语言、壁纸、主题、时区、界面缩放等

## 部署到 GitHub Pages
1. 把 `index.html` 和本文件上传到仓库根目录。
2. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main` / `(root)`，保存。
3. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 通过 GitHub Pages 的 https 地址打开，相机、录音、定位、系统指纹 / 人脸验证才可用（本地文件方式不行）。

## 配置和风天气
1. 在 [和风天气控制台](https://console.qweather.com) 创建项目和 API KEY，并在「设置」里查看你专属的 **API Host**。
2. 打开桌面里的「天气」，点右上角 ⚙，填入 API Host 和 API KEY，点「保存并测试」。

⚠️ **不要把 API KEY 写进代码再上传到公开仓库。** 本仓库的 `index.html` 里密钥是空的，密钥只保存在每个人自己浏览器的本地存储里。

## 数据与安全说明
- 所有文件、设置、书签、密码等都只保存在浏览器本地（localStorage / IndexedDB），不上传服务器。
- 锁屏是页面内的前端锁屏，能挡住旁人随手使用，但不是强加密，防不了懂技术的人。
- 书签里保存的网站密码是明文存放在本地的，请勿保存重要账号。
